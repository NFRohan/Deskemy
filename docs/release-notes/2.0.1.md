# Deskemy 2.0.1

A fix-up release for 2.0. If you installed Deskemy for the first time with
2.0.0, please update: this fixes your library not being saved.

## Fixes

- **Your library is saved again on a fresh install.** On a new install of
  2.0.0 (with no library from 1.x to carry over), Deskemy never created its
  database, so every course you added was gone the next time you opened it.
  2.0.1 creates it on first launch. Courses added on 2.0.0 weren't saved, so
  add their folders once more — they'll stay this time. If you updated from
  1.x, your library was never affected.
- **Mini player across monitors with different scaling.** Dragging the mini
  player onto a monitor with another scale (say 100% and 150%) could make it
  jump and bounce back. It now crosses over smoothly and stays under your
  pointer. Thanks to @ihor-sokoliuk for the report (#8).
- **No more snapping while dragging the mini player.** Windows no longer
  sticks it to screen edges or snaps it into half or quarter layouts as you
  move it.
- **Leaving the mini player on another monitor** brings the full window back
  on that monitor, instead of on the one it started from.

## Installing and updating

- **From 2.0.0 or 1.x:** accept the update when it's offered, or install one
  of the files below over it.
- **Setup** (`deskemy_2.0.1_x64-setup.exe`): per-user, no admin needed.
- **MSI** (`deskemy_2.0.1_x64_en-US.msi`): per-machine, in Program Files.
- **Portable** (`Deskemy_2.0.1_x64-portable.zip`): extract and run; everything
  stays in its folder.

Checksums are in `SHA256SUMS.txt`.

## Known issues

- The first launch straight from the setup's "Run Deskemy" may open minimized
  or behind other windows. Click Deskemy in the taskbar.
- The mouse's back button works over the video, not over the control bar or
  the title bar.
